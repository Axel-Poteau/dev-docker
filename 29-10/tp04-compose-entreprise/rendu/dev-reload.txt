# Essai 1 : bind mount ./apps/shopapi/src:/app/src:ro + node --watch (compose.override.yml), Docker Desktop Linux
$ curl -s localhost:3000/health
{"status":"ok"}
$ sed -i "s/{ status: 'ok' }/{ status: 'ok', reloaded: true }/" apps/shopapi/src/server.js
$ docker compose logs --since 8s api | grep -v "request completed"
$ curl -s localhost:3000/health
{"status":"ok"}
=> pas de "Restarting" dans les logs : le partage de fichiers de la VM Docker Desktop ne relaie pas les événements inotify
   (un fichier remplacé par renommage, comme avec sed -i, n'est même pas visible dans le conteneur ; une écriture sur place l'est, mais sans événement)
